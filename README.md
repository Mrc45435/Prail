### Prail ###

Un joc en què controles un home anomenat Alex que roba objectes de valor a causa de les seves dificultats econòmiques. Hauràs d'evitar els guàrdies i les càmeres fent servir un gadget i una habilitat especial per completar el joc!

Aquesta és la primera i segurament última versió d'aquest joc, un projecte del Treball de Recerca (TR).

### Com instal·lar i jugar el joc ###

1. Descarregar el joc:
Fes clic al botó verd <> Code a la part superior d'aquesta pàgina i selecciona Download ZIP. Un cop descarregat, extreu la carpeta al teu ordinador.

2. Obrir la terminal:
Obre el Símbol del sistema (cmd) o el PowerShell i navega fins a la carpeta on has extret els arxius.

3. Instal·lar Pygame:
Aquest joc necessita la llibreria gràfica pygame per funcionar. Per instal·lar-la, escriu la següent comanda a la terminal i prem Enter:

   pip install pygame

4. Executar el joc:
Un cop s'hagi instal·lat Pygame, pots iniciar el joc amb la següent comanda:

   python prail.py
